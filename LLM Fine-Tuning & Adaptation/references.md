## Terms & Phrases Explained

| Term | Plain-English meaning |
|---|---|
| PEFT | Parameter-Efficient Fine-Tuning; methods that adapt models by training a smaller set of parameters. |
| TRL | Hugging Face's library for training transformer models with methods including supervised and preference-based approaches. |
| Transformers | Hugging Face's library and ecosystem for working with transformer-based models. |
| bitsandbytes | A library commonly used for memory-efficient quantization and optimizer components in deep-learning workflows. |
| vLLM | An inference engine designed for efficient LLM serving. |
| AI RMF | NIST's Artificial Intelligence Risk Management Framework for managing AI risks. |
| Generative AI Profile | NIST guidance focused on risks and risk-management considerations for generative AI. |
| HIPAA | U.S. rules covering protected health information in their applicable contexts. |
| GDPR | European Union regulation governing processing of personal data within its scope. |
| LoRA paper | The research paper introducing Low-Rank Adaptation for parameter-efficient model adaptation. |
| QLoRA paper | The research paper introducing a memory-efficient approach combining quantized model loading with LoRA adaptation. |
| DPO paper | The research paper introducing Direct Preference Optimization. |
| Model revision | A specific immutable or identifiable version of a model repository/artifact. |
| Library version | The exact released version of a software dependency used by an experiment. |
